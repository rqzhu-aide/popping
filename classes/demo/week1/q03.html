In gradient boosting, what happens when the learning rate is very small (e.g., 0.001) versus very large (e.g., 1.0)?

Consider the following XGBoost setup:

import xgboost as xgb
from sklearn.model_selection import train_test_split

# Small learning rate — slow learning, needs more trees
model_slow = xgb.XGBClassifier(
    learning_rate=0.01,
    n_estimators=500,
    max_depth=3
)

# Large learning rate — fast learning, fewer trees
model_fast = xgb.XGBClassifier(
    learning_rate=1.0,
    n_estimators=50,
    max_depth=3
)

Which model would you expect to generalize better, and why? What is the trade-off?
